Store Orders API

REST API for products and orders — Java 21, Spring Boot 3, JPA, H2.

GET/api/productsList products (?category=)
GET/api/products/{id}Get one product
POST/api/productsCreate a product
PUT/api/products/{id}Update a product
DELETE/api/products/{id}Delete a product
GET/api/ordersList orders (?status=)
POST/api/ordersPlace an order
PATCH/api/orders/{id}/statusChange order status
